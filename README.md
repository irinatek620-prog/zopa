# Love Quiz (Liebe)

Простой настольный проект на Python/Tkinter: небольшая «игра-вопрос» с эффектом "фейкового" предупреждения и анимацией сердечек.

Файлы в репозитории

- `love_quiz.py` — главный скрипт (GUI на Tkinter). Содержит безопасную, переработанную версию исходного кода.

Как запустить

1. Скачайте репозиторий или конкретный файл:
   - Репозиторий: https://github.com/irinatek620-prog/zopa
   - Файл: https://github.com/irinatek620-prog/zopa/blob/main/love_quiz.py
   - Raw: https://raw.githubusercontent.com/irinatek620-prog/zopa/main/love_quiz.py

2. Убедитесь, что у вас установлен Python 3.

3. Запустите в терминале:

   python3 love_quiz.py
